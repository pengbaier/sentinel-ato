      How a verdict is made

      Five layers; code keeps the last word.

      1

      Features

      Each session compared with the user’s own history and with all users.

      2

      Rules → floor

      Impossible travel, credential stuffing, reset-then-payout set a minimum risk.

      3

      Anomaly model

      An Isolation Forest flags what is unusual for this user.

      4

      AI investigator

      Claude explains the case and may raise risk, never lower it.

      5

      Policy engine

      Plain code picks allow, MFA challenge or lock.

      Sponsor tools

      PRISM by Block Convey

      Observability and guardrails for AI agents. Every investigation is sent as a trace (case, floor, verdict, rules fired) so an auditor can replay why an account was locked; support-chat text goes through PRISM’s prompt-injection guardrail.

      Visit PRISM → Docs

      Nicrron

      One OpenAI-compatible API for many models. Sentinel calls Claude Sonnet 5.5 / Opus 5.5 through it, with failover and free cached answers for repeat cases. A full 695-session run cost about $0.75.
